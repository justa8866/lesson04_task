# Lekcja 04 - Zadania 1-20

Rozwiązania 20 zadań z lekcji **Podstawy Python - składnia, typy i operatory**.

Każde zadanie znajduje się w osobnym pliku, od `zadanie_01.py` do `zadanie_20.py`.

## Uruchamianie

Do uruchomienia zadań potrzebny jest Python 3. Skrypty nie wymagają instalowania dodatkowych bibliotek.

Otwórz terminal w folderze projektu i uruchom wybrany plik:

```bash
python zadanie_01.py
```

Aby uruchomić inne zadanie, zmień numer w nazwie pliku, np. `python zadanie_18.py`.
