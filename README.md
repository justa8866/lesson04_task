Rozwiązania z lekcji **Podstawy Python - składnia, typy i operatory**.

## Uruchamianie

Otwórz folder w VS Code i uruchom wybrany plik, np.:

```bash
python zadanie_01.py
```

Każde zadanie jest osobnym skryptem, bez dodatkowych bibliotek.

**Uwaga do zadania 13:** reguła 3-sigma zastosowana do pięciu wskazanych pomiarów nie wykrywa 190 jako anomalii, mimo przykładowego wyniku w PDF.

**Uwaga do zadania 18:** zakresy ciśnienia są przykładowymi regułami walidacji technicznej; materiał nie podaje granic.
